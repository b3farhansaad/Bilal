## ✅ إعادة التشغيل التلقائية

لما أي سيلف بوت يقع أو يكرش:
- **ينتظر 5 ثواني** ثم يُعيد التشغيل تلقائياً
- **حد أقصى 10 إعادات** في الساعة الواحدة (حماية من الكراش المتكرر)
- لو وقف **يدوياً** (بزر إيقاف الكل أو `!pstop`) → **لا يُعاد تلقائياً**
- رقم الإعادات يظهر في لوحة التحكم بجانب كل حساب (🔄2x)

## أوامر بوت التحكم (Panel)

### 📋 إدارة الحسابات
| الأمر | الوصف |
|-------|--------|
| `!panel` | لوحة التحكم الكاملة بأزرار |
| `!pstatus` | حالة كل الحسابات بالتفصيل |
| `!pstart` | تشغيل كل الحسابات المحفوظة |
| `!pstop` | إيقاف الكل يدوياً (لن تُعاد تلقائياً) |
| `!prestart` | إعادة تشغيل كل الحسابات |
| `!prestart <userId>` | إعادة تشغيل حساب محدد |
| `!pkick <userId>` | إيقاف حساب يدوياً (بدون حذف) |
| `!premove <userId>` | إيقاف وحذف حساب نهائياً |

### 👑 إدارة الأدمن
| الأمر | الوصف |
|-------|--------|
| `!addadmin <userId>` | إضافة أدمن جديد |
| `!deladmin <userId>` | إزالة أدمن |
| `!admins` | قائمة كل الأدمن |

### ℹ️ معلومات
| الأمر | الوصف |
|-------|--------|
| `!pstats` | إحصائيات البانل (uptime, إعادات, ...) |
| `!phelp` | قائمة الأوامر كاملة |
